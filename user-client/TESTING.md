# L4 用户端异常路径测试清单

这份清单用于在 Linux 虚拟机中逐项验证用户端异常处理。每完成一项，将“实测结果”改为“通过”，并记录必要的现象或截图名称。

## 测试环境

- 系统：Ubuntu 22.04 虚拟机
- 服务端：`ecp-server`
- 用户端：`ecp-user`
- 地图服务：腾讯地图 WebServiceAPI / JavaScript API GL
- 测试账号：使用项目现有测试手机号
- 测试方式：服务端先启动，用户端通过 `config/app.ini` 连接服务端

## 执行前检查

- [ ] 已在 VM 中完成构建：`bash scripts/build-all.sh`
- [ ] 已启动服务端：`./build/bin/ecp-server`
- [ ] 已确认服务端端口：`ss -lntp | grep 9527`
- [ ] 已准备用户端配置：`config/app.ini`
- [ ] 已确认地图 Key 没有提交到 Git
