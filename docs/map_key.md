## 1. 为什么需要这个 Key `[说明书]` 1.4

说明书正文两处明文点名**腾讯地图 Web API**，厂商不是我们选的，没有讨论余地：

- **附近充电站查询**：「……调用腾讯地图 Web API 将地址转换为经纬度坐标；按距离由近及远展示充电站列表……」
- **一键导航**：「……系统调用腾讯地图完成导航。调用腾讯地图 Web API（**QWebEngineView 加载**）；输入起点（当前位置）和终点（目标电站）；提供驾车/步行多种出行方式选择……」

调用腾讯位置服务的任何接口都必须带一个 Key，所以每个要跑用户端地图功能的人都得有自己的 Key。

| 项 | 结论 | 标记 |
| --- | --- | --- |
| 地图厂商 | 腾讯地图（腾讯位置服务 lbs.qq.com） | `[说明书]` 1.4 |
| 加载方式 | QWebEngineView 加载网页 | `[说明书]` 1.4 |
| Key 归属 | **每人各申请一个**，不共用 | `[本组自定]` |
| Key 存放 | `config/app.ini` 的 `[map] key=`，不入库不提交 | `[本组自定]`，conventions §6 |

## 2. 申请步骤

全程免费，个人开发者身份即可，大约 10 分钟。

1. 打开 <https://lbs.qq.com/>，用**微信或 QQ** 登录注册开发者账号。
2. 完成**实名认证**（个人认证：身份证 + 人脸，即时通过）。未实名无法创建 Key。
3. 控制台 → **应用管理 → 我的应用 → 创建应用**。应用名随便填，例如「充电桩管理平台」。
4. 在该应用下**添加 Key**，勾选启用的产品：
   - **WebServiceAPI** —— 地址解析、逆地址解析、路线规划走这个（说明书 1.4 两处功能都在这里）
   - **JavaScript API GL** —— QWebEngineView 里那张网页地图走这个
5. 配置 Key 的授权与安全：
   - **域名白名单**：JS API 用。本机调试填 `localhost`；如果页面是从本地文件加载的见第 5 节。
   - **IP 白名单**：WebService 用。本机调试可留空或填 `0.0.0.0/0`；**答辩演示机的出口 IP 提前加进去**，现场再改来不及。
   - **签名校验（SK）**：可选，开了之后请求要拼 sig。我们是课程项目，**建议不开**，白名单够用了。
6. 复制 Key 字符串，填进本地 `config/app.ini`：

   ```ini
   [map]
   key = 你自己的Key
   ```

> 一个账号最多创建 **10 个 Key**。我们一人一个账号一个 Key，用不着这么多。

## 3. 免费额度（个人开发者）`[本组自定]` 记录

腾讯于 **2025-03-18 公告、2025-04-17 生效**，下调了个人开发者部分基础接口的额度。所以网上 2024 年以前的教程里「统一 1 万次/日」的说法**已经过时**，现在是分接口给的：

| 接口 | 个人开发者 | 企业认证开发者 | 我们用不用 |
| --- | --- | --- | --- |
| 地址解析（地址 → 经纬度） | **6,000 次/日** | 3,000,000 次/日 | ✅ 说明书 1.4 附近充电站查询 |
| 逆地址解析（经纬度 → 地址） | **6,000 次/日** | 3,000,000 次/日 | ✅ 录入电站坐标时用 |
| 关键词输入提示（suggestion） | **6,000 次/日** | 300,000 次/日 | ✅ 地址输入框联想，替代地点搜索 |
| 路线规划（驾车/步行等全部方式） | **6,000 次/日** | 300,000 次/日 | ✅ 说明书 1.4 一键导航 |
| 距离矩阵 | **6,000 次/日** | 300,000 次/日 | ⬜ 备用 |
| **地点搜索、POI 详情查询** | **200 次/日** ⚠️ | 2,000 次/日 | ❌ **不用**，见第 4 节 |
| 多边形地点搜索、智能硬件定位 | **0（个人已关闭）** | — | ❌ 用不了 |
| **并发限制** | **5 次/秒** | 100 次/秒 | 单机调试够用 |

### 三个容易理解错的点

1. **额度按「账号」算，不是按「Key」算。** 一个账号下 10 个 Key 分的是同一份池子，多建几个 Key 不会多出额度。conventions §6.2 里「按 Key 计算免费额度」的说法要更正（见第 7 节）——不过**「每人各申请各的」这个结论仍然成立**，因为额度绑在各自的微信/QQ 账号上，各人一个账号就是各人一份 6,000 次。
2. **JS API GL 的地图渲染（瓦片、缩放、拖动、打点）不消耗上面这些额度。** 吃额度的是「服务类接口」：地址解析、路线规划、搜索。所以大屏和用户端**只显示地图、只打点**的部分，怎么点开都不花钱。
3. **控制台用量统计有 1~24 小时延迟。** 出现「没超额却报此 key 每日调用量已达上限」，多半是统计延迟，或者 Key 泄露被别人刷了——先查白名单。

### 额度不够怎么办

- 优先**缓存**：同一个地址反复解析是最常见的浪费，见第 4 节。
- 控制台 → **配额申请 → 提升配额**，3 个工作日内审批。
- 企业认证后可免费申请提额；商业授权后可购买调用量包（有效期 372 天）。**课程项目不需要走到这一步。**

## 4. 对本项目的具体约束（重要）

### 4.1 电桩/电站坐标一律入库，运行时不调搜索接口

**地点搜索只有 200 次/日**，联调时点几十次就见底了，答辩当天挂掉的风险很高。做法：

- 电站的经纬度作为**字段存在我们自己的 SQLite 里**（`t_station` 的 `lng` / `lat`，见 [db-schema.sql](db-schema.sql)），种子数据录入时就填好。
- 说明书 2.x 管理端「新增电站」本来就要求手填经纬度，本来也不需要搜索接口。
- 用户输入地址定位（说明书 1.4「手动输入地址」）走**地址解析 6,000 次/日**，额度充足；要做输入联想就用**关键词输入提示**，也是 6,000 次/日。**不要用地点搜索。**

### 4.2 相同地址的解析结果要缓存

用户端每次进首页都解析一遍同一个地址是纯浪费。解析过的「地址 → 经纬度」结果缓存起来（内存 map 或落一张小表都行），命中就不发请求。腾讯官方 FAQ 也是这么建议的。

### 4.3 QWebEngineView 里不能用 `file://` 加载地图页

JS API GL **必须在有 Web 服务的环境下运行**，`file://` 协议直接白屏。两处都会踩：

- **L4 用户端**：导航页面不要 `load(QUrl::fromLocalFile(...))`，用 `setHtml()` 配一个 `baseUrl`，或者本地起个轻量 http 服务再 `load(QUrl("http://localhost:PORT/..."))`。
- **L5 大屏**：`dataviz/` 如果之后要加地图，双击 html 打开是不行的，得 `python3 -m http.server` 起服务。目前大屏只有 ECharts，不受影响，但加地图前要先想到这条。

### 4.4 坐标系是 GCJ-02

腾讯地图用 **GCJ-02（火星坐标）**。我们的种子坐标（`config/app.ini.example` 里深圳市民中心 `114.0650, 22.5470`）按 GCJ-02 录入，全项目统一，不要混进 WGS-84 的原始 GPS 坐标，否则地图上点位会偏移几百米。另外腾讯 JS API 的坐标构造是 **`{纬度, 经度}` 顺序**（`LatLng(lat, lng)`），和我们库里 `lng, lat` 的字段顺序相反，**转换处最容易写反**。

### 4.5 答辩前一天各自查一次额度

控制台 → 配额管理，确认当天没跑满、白名单里有演示机的 IP。

## 5. Key 的保管 `[本组自定]`

规则见 [conventions.md §6.1](conventions.md#61-规则)，这里只强调三条：

- Key **只存本地 `config/app.ini`**，该文件已在 `.gitignore` 里（`config/*.ini` + `!config/*.ini.example`）。
- 代码里一律 `QSettings` 读，**禁止硬编码到 `.cpp` / `.h` / `.pro` / 提交信息**，也不要在示例代码里编造假 Key 占位。
- **万一提交了**：Key 留在 git 历史里删不干净，正确处置是去控制台**删掉这个 Key 重建一个**，而不是改一次提交了事。

答辩被问「数据安全怎么考虑的」，这条和密码 SHA-256、SQL 参数绑定并列，是能讲的实事（`[说明书]` 2.2）。

## 6. 一句话给 agent

> 生成任何涉及地图的代码：Key 从 `config/app.ini` 读；地址解析和路线规划可以调；**地点搜索/POI 详情不要调**（个人额度只有 200 次/日）；电站坐标从我们自己的 SQLite 取，不要现场去腾讯搜；网页地图不能用 `file://` 加载。
