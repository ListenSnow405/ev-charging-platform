## pile-simulator 电桩模拟器

模拟设备侧：注册上线 → 周期上报状态与电量 → 接收服务端重启指令。
对应 [说明书] 1.4「远程重启（模拟向电桩发送重启指令）」与 docs/protocol.md 第 4.5 节（命令字 9001–9006）。

```bash
./build/bin/ecp-pile-sim SZ001-01              # 默认连 127.0.0.1:9527
./build/bin/ecp-pile-sim SZ002-03 127.0.0.1 9527
```

## 为什么需要它

没有真实电桩硬件，管理端的「远程重启」「电桩状态分布」「在线率」都无从演示。
这条线在分工方案里被单列出来，就是因为它最容易被漏掉——不显式派人，最后没人做。

## 现状

服务端设备段 9001–9006 已全部实现，完整链路已打通：模拟器注册上线 → 周期上报 → 管理端点「远程重启」
（2112）→ 服务端查在线设备连接 → 9003 下发 → 模拟器日志可见。充电起停 9005/9006 同链路。

可继续做的（非必需）：批量拉起多个电桩实例便于大屏演示；模拟故障状态上报，用于演示管理端故障电桩列表。
