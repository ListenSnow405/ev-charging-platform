## 本模块特有规则

1. **QtCharts 需单独安装**（`bash scripts/check-env.sh L3` 会给出命令）。`.pro` 用 `qtHaveModule(charts)` 守卫，未装也能编译，界面显示安装提示；装好后重新 `qmake6` 自动启用。
2. **Qt6 的 charts 类不在 `QtCharts` 命名空间里**，不要写 `QT_CHARTS_USE_NAMESPACE`（Qt5 写法）。
3. **网络回调在 UI 线程**，当前无需跨线程；若日后引入工作线程，跨线程更新控件一律信号槽 + `Qt::QueuedConnection`。
4. **金额从服务端收到的是「分」**，显示时用 `ecp::fenToYuan()`，不要自己除。
5. 先用 `mock/` 下的假数据把界面做完，W3 再换真实链路——不要等服务端。
